---
description: Run the local Next.js dev server for ChromaMe
---

1. Ensure dependencies are installed in `web/`.
// turbo
2. Run `npm install` from `web/` if `node_modules` is missing.
// turbo
3. Start the dev server with `npm run dev` from `web/`. Default URL: http://localhost:3000.
4. Open a browser preview pointed at http://localhost:3000.
